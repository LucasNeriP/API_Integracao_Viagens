ARQUIVO: tests/test_api.py

FUNÇÃO DO ARQUIVO
Este arquivo testa os comportamentos gerais e globais da API. Ele garante que o
endpoint web processe listas com múltiplas empresas juntas, mantenha a ordem dos
itens, descarte campos extras não previstos e responda corretamente para listas
vazias.

COMO ELE FUNCIONA
Ele utiliza o cliente de teste `cliente` (configurado em `tests/conftest.py`) para
enviar requisições POST com diferentes combinações de listas para a URL
`/api/v1/viagens/normalizar` e inspeciona as respostas retornadas pela aplicação.

TESTES IMPLEMENTADOS

* test_normaliza_o_exemplo_oficial_das_tres_companhias(cliente)
  Envia uma lista contendo uma viagem de cada uma das três empresas principais juntas
  (Progresso, Rota e Gontijo).
  Verifica se:
  - O código de resposta é 200 (Sucesso).
  - O campo "total" é igual a 3.
  - Cada uma das viagens na resposta bate com seu respectivo gabarito oficial.

* test_preserva_a_ordem_mesmo_quando_os_objetos_chegam_embaralhados(cliente)
  Envia as empresas em uma ordem diferente da habitual (Gontijo primeiro, depois
  Progresso e por fim Rota).
  Verifica se a API respeita estritamente a ordem de envio na saída, devolvendo
  [Gontijo, Progresso, Rota].

* test_inclui_sertao_bus_no_mesmo_endpoint(cliente)
  Envia uma viagem da Sertão Bus e confere se a API a processa com sucesso (status 200)
  junto às demais sem exigir um endpoint separado.

* test_ignora_campos_adicionais_que_nao_fazem_parte_do_contrato(cliente)
  Adiciona campos inventados e inúteis ao payload (ex: "observacaoInterna" e
  "codigoSecreto").
  Verifica se a API processa a viagem normalmente e descarta esses campos extras no
  resultado final, mantendo a saída limpa e aderente ao contrato.

* test_lista_vazia_devolve_total_zero(cliente)
  Envia uma lista vazia `[]`.
  Verifica se a API responde com status 200 e o JSON `{"total": 0, "viagens": []}`.

FLUXO DO CÓDIGO
O Pytest executa cada uma dessas funções de forma independente, disparando
chamadas HTTP simuladas contra a rota da API e validando as respostas com `assert`.

ARQUIVOS RELACIONADOS
- app/main.py: Rota testada.
- tests/conftest.py: Fornece o `cliente`.
- tests/exemplos.py: Fornece as variáveis de exemplo e gabaritos.

RESUMO
O tests/test_api.py valida as regras gerais da API web: processamento de múltiplas
empresas em conjunto, preservação de ordem, descarte de dados supérfluos e suporte a
listas vazias.
